🐾 Veterinaria+

Aplicación web para administrar una veterinaria.
Incluye un backend en Java por capas con Servlets y un frontend en JavaScript.

📁 Estructura del Proyecto (Backend)

src/main/java/pe/edu/veterinariaplus/
│
├── business/       → Lógica de negocio
├── exceptions/     → Excepciones personalizadas
├── filters/        → Filtros de seguridad y validación
├── model/          → Modelos / entidades (Mascota, Cliente, Cita, etc.)
├── service/        → Servicios y acceso a datos
├── servlets/       → Controladores HTTP (endpoints)
├── util/           → Funciones de ayuda
└── utils/          → Utilidades adicionales

App.java            → Punto de entrada opcional
